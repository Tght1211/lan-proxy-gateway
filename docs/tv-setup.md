# 智能电视 / 盒子接入

[返回图文手册](user-guide.md)

电视不安装网关程序。先在 Mac / Linux 主机完成代理与接入配置。不同电视品牌的菜单名称不同，以下按功能找对应选项。

## 推荐：连接 Mac 热点

有线 Mac 完成 [热点路线](user-guide.md#wifi) 后，电视进入“设置 → 网络 / 无线网络”，选择新热点并输入密码。IP 和 DNS 自动获取，不设置设备代理。

打开实际需要的视频或商店，回 App 查看这台电视的连接和实际出口。

## 进阶：静态网关

先完成 [静态网关主机设置](user-guide.md#static)。电视进入当前有线/无线网络的高级设置，将 IP 改为手动：

| 字段 | 填写 |
|---|---|
| IP 地址 | 同子网未占用的电视地址，不能与电脑相同 |
| 掩码 / 前缀长度 | 实际网络值 |
| 网关 / 路由器 | 网关电脑的局域网 IP |
| DNS | 使用网关 DNS 时，填电脑 IP；前提是该服务已启用且可达 |
| 代理 | 无 / 关闭 |

电视完全不提供手动网关选项时，优先使用热点；若支持 HTTP 代理，可看 [HTTP 路线](user-guide.md#http)，但它只影响遵循代理设置的应用。

## 验证和停用

视频服务是否可用取决于账号、地区、上游及分流，不保证解锁。仅有联网图标不等于影片可播放，按 [验证步骤](user-guide.md#verify) 检查。

停止时，热点切回原 Wi-Fi；静态网关恢复自动获取或原参数；HTTP 方式关闭代理。见 [恢复网络](user-guide.md#stop)。
