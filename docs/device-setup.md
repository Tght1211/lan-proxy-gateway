# 设备接入方式详解（v4）

v4 只有一种接入方式：**把设备的 网关 + DNS 都指向 gateway 电脑的局域网 IP**。
没有"填代理"模式——那不是网关级方案，且市面上代理软件已经够多了。

> Windows 和普通路由器不在支持范围内。请在常驻的 macOS 或完整 Linux 电脑上运行本服务。

---

## 填什么

| 字段 | 填什么 |
|---|---|
| 网关 (Gateway / Router) | 电脑的局域网 IP |
| DNS 服务器 | 同一个 IP |
| 子网掩码 | `255.255.255.0`（保持原值） |
| IP 地址 | 保留自动获取，或手动设成同网段静态 IP |

保存 → 重连 Wi-Fi 即可。**网关和 DNS 必须同时改**：只改网关不改 DNS，设备不会被接入（透明转发依赖本机的 DNS 服务）。

## 原理（30 秒版）

设备把默认路由指向电脑 → 电脑的防火墙把 TCP 转给本服务的透明转发器 →
转发器按出口配置直连或经上游代理发出；DNS 查询由本服务转发到上游 DNS。

## 各设备具体步骤

| 设备 | 路径 |
|---|---|
| iPhone / iPad | 设置 → Wi-Fi → 点当前网络右侧 ⓘ → 配置 IP → 手动：IP 填同网段空闲地址、子网掩码 255.255.255.0、路由器=电脑 IP；配置 DNS → 手动：电脑 IP |
| Android | 设置 → WLAN → 长按当前网络 → 修改网络 → 高级选项 → IP 设置=静态 → 网关/DNS 填电脑 IP |
| Switch | 设置 → 互联网 → 互联网设置 → 选 Wi-Fi → 更改设置 → IP 地址设置=手动 → 网关/DNS 填电脑 IP |
| PS5 | 设置 → 网络 → 设定 → 设置互联网连接 → 选 Wi-Fi → 高级设定 → IP 地址=手动 → 默认网关/DNS 填电脑 IP |
| Apple TV | 设置 → 网络 → Wi-Fi → 配置 IP → 手动；配置 DNS → 手动：电脑 IP |
| 智能电视/盒子 | 设置 → 网络 → 有线/无线 → IP 设置=手动 → 网关/DNS 填电脑 IP |

更细的图文步骤见 [switch-setup.md](switch-setup.md) / [ps5-setup.md](ps5-setup.md) / [appletv-setup.md](appletv-setup.md) / [tv-setup.md](tv-setup.md)。

## 建议：给设备固定 IP

设备使用手动网关时通常也需要手动 IP。请选同网段、未占用且避开 DHCP 池的地址，或在路由器中做 DHCP 静态绑定。

## 恢复

把设备的网络设置改回"自动获取(DHCP)"，或忘记 Wi-Fi 重连即可。
