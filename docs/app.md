# macOS App 功能参考

[返回文档目录](README.md) · [第一次使用：图文手册](user-guide.md)

本页解释运行机制与统计口径。安装和操作顺序请先读手册；界面入口按 v4.5.6 源码核对。

## 页面与入口

| 页面 | 内容 |
|---|---|
| 网络总览 | 在线设备、本季度已记录代理/直连流量、近期吞吐与出口健康；连接拓扑和下方出口卡片 |
| 配置规则 | 分流规则与自学习；搜索、动作/来源筛选、分组、分页及变更对比 |
| 设备接入 | Wi-Fi 热点、静态 IP、PAC、HTTP 代理四个入口；已记录设备及详情 |
| 流量记录 | 按设备、出口、结果筛选，搜索服务/域名；自动学习入口 |
| 设置 | 功能与接入、通用、版本与更新、CLI 与 Agent、实时日志 |

App 与 CLI 使用同一个 Go 核心、配置和本机管理 API。另开前端不会另建一个数据面进程。核心启停在右上角 **…**；退出界面不等于停止核心。已访问页面保留搜索、筛选与滚动位置，隐藏页面暂停相关投影和动画。

## 接入方式

[热点](user-guide.md#wifi) 使用 macOS 互联网共享提供的 DHCP/NAT；App 检测并接管对应 Wi-Fi 网络。热点名称、安全性、密码和信道仍由系统配置。App 的名称/密码功能是备忘；密码备忘存储在系统钥匙串，不等于读取或修改系统热点密码。

[静态网关](user-guide.md#static) 使用主机的局域网入口。热点接管和静态网关接管是两种互斥的核心模式，切换需重新应用核心；HTTP/PAC 可以同时启用。静态接入应按真实子网、DNS 配置设置客户端，不应把固定示例地址照搬。

## 局域网 HTTP 代理接入

操作步骤见 [HTTP 图文教程](user-guide.md#http)。默认关闭，默认端口 **17894**，支持普通 HTTP 请求与 HTTPS CONNECT。只接管愿意使用代理的应用，不承载任意 UDP。设备策略和分流规则同样生效。

可选择无需认证或 HTTP Basic。接入凭据与上游代理认证独立；密码保存在权限为 `0600` 的配置文件中，不出现在状态 API 或命令行参数中。已有密码时留空保留，改为无需认证会清除接入凭据。仅在可信局域网使用 Basic。

v4.5.6 支持精确的私有/回环来源 IP 免密名单，按实际 TCP 对端匹配，不信任转发请求头。本机隧道连接可能共享回环来源，需要按实际接入范围配置。名单默认不豁免设备。

保存后运行中的新版核心热应用。端口冲突会报告错误并保留旧监听；改端口或停用服务会断开已有连接。可在 **设置 → 功能与接入** 操作相同配置。

## PAC 自动代理

操作步骤见 [PAC 教程](user-guide.md#pac)。地址格式为 `http://<本机局域网地址>:<HTTP代理端口>/proxy.pac`，共用 HTTP 监听器。

PAC 下载不要求认证、不含密码；代理请求仍需遵循认证策略。PAC 将请求交给网关统一分流，不复制整份规则，也不添加代理失败时的客户端直连兜底。服务端无法区分手动 HTTP 与 PAC 配置，记录都属于 HTTP 代理入口。

通过 TCP 隧道连接时，服务端看到的来源可能是隧道客户端，不能由此判断远端真实设备 IP。HTTP 代理 TCP 端口不能充当通用 UDP 隧道终点。

## 分流规则与并发编辑

设备策略优先；其他规则按全局顺序首次命中。每条规则有独立动作，分组不等于多个代理出口。搜索、来源、动作筛选和分页只改变显示，应用时保留隐藏规则。已有连接不会随规则保存迁移出口。

v4.5.6 的“查看变更”区分自己的草稿和外部更新；无冲突变更可合并，有冲突时逐项选择，合并到草稿后再应用。仅打开编辑器不应产生草稿修改。并发保存保护需要所有写入方使用兼容的新核心/CLI；手工修改配置不参与同一文件锁流程。

## 自动学习

代理模式且允许直连时，对没有匹配明确规则的目标先试直连。直连失败或符合首响应重试条件后，代理收到数据才积累证据；24 小时内达到当前确认次数后，按保存方式自动写入精确域名代理规则或等待确认。默认确认次数为 1，可设 1–10，以实际设置为准。

“已响应”不是业务成功；不会任意重放 TLS 握手以外的应用请求数据。明确规则和禁止直连要求优先，两路失败不生成规则。调整学习设置不会追溯生成全部规则。

待确认、已保存、暂停学习分别管理；支持服务、路由、范围、搜索和分页，每页 50 条。旧版学习规则保留原来的方向与范围。撤销会移除对应学习规则并暂停学习；恢复后重新观察，不立即产生规则。暂停不等于拒绝访问。

设备临时保护的阈值、窗口和恢复时间以运行遥测为准，不能沿用旧文档里的固定分钟数。

## 流量历史与统计口径

- 统计仅包括经过网关的转发字节，不含绕行流量、Mac 其他应用的代理流量或 TCP/IP/代理握手开销，不等于服务商账单。
- 日汇总按本机日历日期、设备 IP、接入方式、实际出口、代理入口和目标域名/IP 保存；每 5 秒原子写入 `usage-history.json`，正常退出再次保存。异常退出可能损失最后一段尚未落盘的数据。
- 已建立连接按实际出口计数；回退到直连计入直连，代理入口取连接时的值。旧版未分类用量不能反推为代理用量。
- 季度数值只合计本季度已保留、已分类的记录。逐条连接仅保存在内存中，最多 72 小时、2000 条，不是长期访问日志。
- 设备按来源 IP 归属；DHCP 改地址、隧道共享来源都可能影响计数和设备识别。

## 健康与隐私

出口卡片分别反映已观察路径与探测。核心独立对本机直连进行百度 HTTP 探测，默认每 10 秒一次、最多等待 8 秒；收到响应只证明该探测路径可达。代理正常不代表所有目标可用，全局健康不是所有业务的成功率。当前只配置一个 HTTP/SOCKS5 上游。

服务名基于目标域名识别，不是远端设备的进程列表。网关不解密 HTTPS，不保存完整 HTTPS 页面内容；fake-IP 映射缓存可能包含访问域名，应作为私人数据保管。App 获取出口公网地址/地区时会访问 `ipwho.is`，结果缓存在内存，失败不影响转发。

本机管理 API 绑定 `127.0.0.1` 且要求独立 Bearer 令牌。令牌保存在配置旁权限为 `0600` 的 `api-token`，CLI/App 自动读取；它与 HTTP 接入用户名密码不是同一种凭据。不要将管理端口当成共享代理端口公开。

## 安装与更新

[安装包说明](download.md) · [更新 App 和核心](user-guide.md#update) · [Agent Skill](agent-skill.md)

DMG 包含核心，CLI 可在“设置 → CLI 与 Agent”安装到 `/usr/local/bin/gateway`。App 下载更新后，按提示更新并重启后台核心，使界面和核心保持兼容。修改设备出口使用 `gateway egress`，保留 Mac 系统代理/DNS；`gateway system-proxy` 是独立的高级操作。

## 本机构建（开发者）

普通用户不需要构建，也不需要在多个 Git 分支中挑选。想复现一个发布版本，应使用对应的 Git 标签；不要仅凭分支名推断它等同于最新 Release。

```bash
make build
make test
make build-app
make dmg VERSION=v0.0.0-dev
make skill VERSION=v0.0.0-dev
```

上面是开发版本标记，不要给未发布代码伪造正式版本号。完整 Xcode 或 GitHub macOS Runner 构建 universal App；只有 Command Line Tools 时，SwiftUI 外壳按本机架构构建。DMG 核心含两种 Mac 架构。

Swift 模型检查：

```bash
bash macos/test-models.sh
```

Go 核心完整回归：

```bash
go test -race ./...
```

发布过程及下载表维护见 [Release 维护说明](releases/README.md)。
