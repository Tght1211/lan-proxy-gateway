# v4.5.2 — 独立直连探测与拓扑交互修复

## 本次更新

- **直连探测有自己的记录**：本机直连每 10 秒独立探测 `www.baidu.com:80`，单次超时 8 秒。使用代理时也会继续直连探测；代理与直连分别显示健康、延迟和历史，不再把代理结果当作直连结果。
- **拓扑图标恢复点击**：图标、标题、说明和节点内部空白都属于同一点击区域；动画层不拦截点击，保留已有性能优化。
- **规则配置更直接**：移除代理源 / 资产视角，统一按全部规则、代理出口、本机直连、拒绝筛选。分组只是组织方式，不是可复用的多出口资产；筛选不删除隐藏规则，不改变原有动作或全局首条命中顺序。
- **版本标识更清楚**：未标记的构建显示开发预览，正式版本正常显示版本号，不再把占位版本当作正式发布。
- **同步 Agent Skill**：补齐新版规则编辑语义、独立出口探测与有界只读摘要；旧核心缺少独立探测字段时不误报。

## 升级说明

- macOS 使用本 Release 的 DMG 更新 App，然后在 App 中重启核心，将内置新版核心同步到系统服务。只更新界面、未更新核心时，不会出现独立直连探测记录。
- 重启核心会短暂中断现有连接；本次升级不要求修改上游代理、设备规则、认证或接入配置。
- CLI 用户更新对应平台的核心并重启已安装服务。外部 Agent 用户同步安装本 Release 的 Skill ZIP。
- 百度探测有响应只表示该探测路径可达，不保证所有网站或所有客户端均可访问。全局稳定性仍是已观察出口的摘要。

## 验证

- Go 全量测试与 race 检查，覆盖独立直连请求、代理失败但直连成功、默认出口兼容及取消处理。
- Swift 模型与投影测试、macOS Release 编译，覆盖独立出口数据、旧核心兼容及版本标识。
- Skill 摘要回归、导出一致性与安装后真实只读调用。
- 实机点击拓扑 Wi-Fi / 设备策略图标与内部空白；规则四种筛选保持原有计数，未保存或改写实时规则。
