# v4.5.6 — 代理免密与规则差异合并

发布于 2026-11-04。

## 本次更新

- **指定来源 IP 免密**：HTTP / HTTPS 代理开启 Basic 认证后，可配置精确的局域网或回环来源 IP 免密，其他来源继续验证用户名与密码。名单支持热更新，HTTP 和 CONNECT 使用同一策略；按实际 TCP 对端匹配，不信任转发 IP 请求头。
- **规则变更对比**：新增“查看变更”，分别展示“我的修改”和“外部更新”，对照新增、删除、内容修改与优先级调整。无冲突的后台更新与草稿自动合并，真正冲突可逐条选择版本，合并到草稿后再应用。
- **保留全局优先级**：按分组显示时不再重排交错规则，修复只打开编辑器就出现未应用修改、随后误报冲突的问题。
- **修复预设重复添加崩溃**：每次插入预设生成独立规则标识，修改预设目标后再次添加同一预设也能正常编辑。
- **避免并发覆盖配置**：规则基线检查与写入在同一跨进程事务内完成；后台学习、撤销与清理读取最新配置后再更新，旧快照保存会被拒绝。配置采用临时文件原子替换，避免读到不完整内容。
- **同步 Agent 支持**：代理状态和 Agent 摘要包含免密名单；更新配置示例、操作说明及相关回归测试。

## 升级说明

- App 与运行中的核心需要同时更新。在“设置 → 版本与更新”安装新版 App，再选择“更新并重启核心”；也可下载本 Release 的通用 DMG 手动安装。核心重启会短暂断开现有连接。
- 保留已有代理地址、认证、规则与学习记录。免密名单默认关闭，不会自动豁免任何设备；在代理设置的“免密来源 IP”中显式填写后生效。
