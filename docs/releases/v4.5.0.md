# v4.5.0 — 网络工作台、流畅导航与分类自学习

## 网络总览与导航

- 使用统一的原生网络工作台：网络总览、配置规则、设备接入、流量记录、设置。
- 首页支持上下滚动：关键指标 → 自然尺寸连接拓扑 → 紧凑出口卡片，每行最多三张；移除独立网络出口菜单。
- 顶部突出在线设备、本季度已记录的代理 / 直连流量、紧凑实时吞吐和全局出口健康。全局健康是已观察出口的摘要，具体问题查看各出口卡片；核心仍只配置一个代理上游。
- 缓存已访问页面，保留筛选、搜索、滚动与编辑状态；隐藏页面暂停流量投影和拓扑动画，减少重复计算。
- 流量与健康投影按轮询缓存；拓扑复用图标路径、连接路径和文字符号，静态交互层不随每帧动画重建。

## 自学习：清楚分类，支持大量记录

- 当前策略为 direct-first：未匹配明确规则的目标先直连，直连失败或满足首响应超时条件后再试代理；代理收到响应数据才记录证据。
- 默认一次有效响应，可配置1–10次；按自动保存 / 待确认设置生成精确域名代理规则。响应预算、最大等待、冷却与临时记忆均可配置；两路失败不生成规则，明确规则及禁止直连要求优先。
- 学习记录先区分待确认、已保存、暂停学习，再按服务、路由、规则范围筛选；支持域名 / 服务 / 原分组搜索，每页50条。
- 已保存记录按服务分段显示，服务优先采用持久化分组，没有可靠识别时显示未分类。旧版直连与后缀规则保留原语义，不擅自扩大匹配范围。
- 大数量徽标单行缩写，精确数量保留在提示与辅助功能中。稳定标识、索引缓存和懒加载减少大量条目的构建开销；不截断实际规则。
- 撤销学习规则会同时暂停学习；恢复只是恢复观察，不立即生成规则。暂停学习不等于拒绝访问。

## 升级说明

1. 安装新版 App；要使用新版核心行为，按需更新并重启核心，系统可能要求管理员授权。重启中断现有连接，客户端需重新连接。
2. 已有显式规则不覆盖；旧版学习规则保留方向，旧版相反方向的候选证据不混用。设置不会追溯批量生成规则。
3. 流量仅统计本网关转发字节，不等同于服务商账单；未经过网关的流量无法计量。旧记录缺失出口信息时不反推分类。
4. HTTP 代理不承载任意 UDP，游戏 UDP / NAT 效果仍需实测；此版本不新增多代理节点池、IPv6透明代理或远程管理入口。
5. Release 包含 macOS universal DMG、macOS / Linux 双架构 CLI、Skill ZIP 与 SHA256SUMS。
