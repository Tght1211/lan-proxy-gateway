# v4.5.5 — 转发稳定性与 PlayStation UDP 修复

发布于 2026-10-27。

## 本次更新

- **更及时的代理故障恢复**：上游代理端口的检查间隔从 30 秒缩短为 5 秒，并与逐域名恢复探测分开执行，避免慢速域名阻塞端口状态检测。探测支持取消，核心退出时不再等待完整拨号超时。
- **修复并发与代理切换**：保护出口异常时间的并发读写；健康探测允许在 HTTP、SOCKS5 和直连拨号器之间切换，避免不同实现写入同一个原子容器时崩溃。
- **减少 TCP 转发分配**：复用每方向 64 KiB 缓冲区，保留实时字节统计和 TCP 半关闭语义。本地 1 MiB 转发基准中，每次操作分配的内存由约 40 KB 降至 7 KB；该结果衡量程序开销，不代表互联网下载速度提升。
- **修复 macOS UDP 转发地址**：UDP fake-IP 中继默认绑定 PF 实际重定向使用的 `127.0.0.1`，让原始目标查询和回包源地址匹配反向转换。Linux 保留原来的监听方式。
- **PlayStation STUN 使用真实地址**：`stun.playstation.net` 及其子域名不再分配 fake-IP，避免额外 UDP 中继套接字改变主机的 NAT 穿透映射；YouTube 等其他服务继续按原有规则代理。

## 升级说明

- macOS App 与核心需要同时更新。v4.5.4 用户可以在“设置 → 版本与更新”安装此版本，再选择“更新并重启核心”。也可以使用本 Release 的通用 DMG 安装 App。
- 启用新版核心会短暂断开现有连接，请在远程游玩或其他重要会话结束后操作。
- 保留已有代理地址、认证、分流规则及学习记录；无需重新配置热点或上游代理。
- 同步提供 Apple Silicon / Intel macOS 通用 DMG、各平台 CLI、Agent Skill ZIP 与 SHA256SUMS。

## 验证与效果边界

- Go 全量测试与 race 检查，覆盖慢速域名探测不阻塞端口恢复、代理类型切换、并发健康快照、UDP 回包地址和 STUN DNS 行为。
- Swift 模型与更新器回归、各平台 CLI 构建、macOS 通用 App 与 DMG 构建由发布流程执行。
- 本机验证热点接管、YouTube 代理连通性、STUN 实际回包及手机蜂窝网络与 PS5 的双向 UDP 流量。
- 本次实测未确认 PS Remote Play 的整体连接等待时间明显缩短；此版本修复已确认的转发与稳定性问题，不承诺缩短所有网络环境下的远程连接耗时。
