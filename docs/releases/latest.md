# v4.5.4 — 应用内下载、安装与更新

发布于 2026-10-09。

## 本次更新

- **应用内安装更新**：在“设置 → 版本与更新”点击“下载并安装更新”，无需打开 GitHub 发布页或手动拖动 App。安装完成后自动退出并重新打开。
- **下载进度与取消**：显示下载百分比和校验、准备、安装阶段；下载与准备阶段可取消，失败后可重试。
- **校验与失败回退**：自动选择通用或当前架构的 macOS 包，校验 SHA-256、应用标识、版本、App 与核心架构及代码签名。先暂存到安装目录所在磁盘，替换失败时恢复旧 App；需要写入权限时由系统请求管理员授权。
- **版本比较**：按版本号判断是否有更新，避免把更旧版本当作新版本，支持从本地开发预览更新到对应正式版本。
- **新版核心一键启用**：核心随 App 下载；更新 App 后在同页选择“更新并重启核心”，保留现有配置与规则。已有开机自启服务继续使用原配置和环境；未运行时只更新核心、不启动。

## 升级说明

- v4.5.3 及更早的 App 尚无应用内安装功能，首次升级到 v4.5.4 请使用本 Release 的通用 DMG，将 App 安装到“应用程序”文件夹。从此版本起，后续正式版本可直接在 App 内安装。
- 更新 App 不主动停止运行中的网关。启用新版核心时，设备连接会短暂中断；可以按需选择启用时机。
- 从开发命令、DMG 或系统隔离目录运行时不支持原地安装，页面会提示将 App 安装到本机。
- macOS 通用 DMG 支持 Apple Silicon 与 Intel Mac；CLI 二进制、Agent Skill ZIP 和 SHA256SUMS 同步提供。

## 验证

- Go 全量测试及 race 检查。
- Swift 模型回归与更新器回归，覆盖版本比较、架构选择、校验文件解析、真实签名测试 App 的 DMG 解包与安装、版本不匹配拒绝、替换失败回退、篡改拒绝及特殊字符路径。
- 真实 GitHub 发布包的下载、SHA-256、架构与签名校验，以及临时目录安装验证。
- macOS Release 编译与 DMG 打包；GitHub Actions 构建各平台附件与通用 macOS DMG。
