# v4.5.3 — 闲置设备折叠与规则配置体验优化

发布于 2026-10-05。

## 本次更新

- **闲置设备默认折叠**：拓扑中灰色设备超过一台时，合并为「闲置设备 · N 台」，点击可展开或收起；只有一台时直接显示。设备恢复流量后自动回到活跃节点，图高随实际显示节点数变化，展开较多设备时沿用整页滚动。
- **从流量记录快捷分流**：点击记录的 PROXY / DIRECT / 回退出口，或右键目标域名，选择「设为直连 / 设为代理」，保存为手动精确域名规则。保存前读取最新规则并检查变化，保存后核验结果；同域名规则合并，不把 IP、端口或 URL 误存为域名规则。
- **规则编辑器更紧凑**：分组与规则表之间支持拖动分隔条；表格展示全局优先级、匹配类型、目标、手动 / 学习来源和出口。支持搜索及出口、来源组合筛选，默认每页 50 条，可选 25 / 100 条。筛选和分页只影响展示，保存仍包含完整草稿。
- **排序保留真实优先级**：无筛选且只有一页时支持拖动排序；筛选或多页时，可在更多菜单中上移 / 下移，按原始规则位置调整优先级。
- **详情弹窗按内容适配**：网络入口和探测记录使用紧凑弹窗，设备策略随设备数量增高，接入说明、服务记录及设置使用各自尺寸；超出屏幕或内容高度上限时滚动，关闭入口保持在顶部。

## 升级说明

- macOS 使用本 Release 的通用 DMG 更新 App，支持 Apple Silicon 与 Intel Mac。本次新增功能位于界面层，已运行 v4.5.2 核心的用户无需为这些界面改动重启核心。
- 从更早版本升级时，请参考 v4.5.2 的核心升级说明；新 App 不会补齐旧核心缺失的独立直连探测数据。
- 快捷分流适用于所有设备的后续新连接，设备级策略仍优先，已经建立的连接不改变出口；规则仅匹配所选完整域名，不自动扩大到子域名。
- 折叠闲置设备保留设备记录、用量及路由配置。CLI 和 Agent Skill 随版本一同提供，下载后可用 SHA256SUMS 校验。
