# v4.4.0 — 代理 Wi-Fi 与按设备代理用量

## 连接 Wi-Fi 即可接入代理

- 新增 macOS 热点接管：Mac 通过以太网上网，使用系统互联网共享创建 Wi-Fi；Switch、PS5 和手机自动获取 IP、网关及 DNS，无需手动选择空闲地址。
- 接管仅作用于独立的热点网络，保留 Mac 原有默认路由、系统代理和 DNS。系统共享重启或热点地址变化后自动重新检测。
- 引导区分 Wi-Fi 关闭、共享未就绪、等待接管、正在确认和接管成功；以运行中核心的结果确认状态。
- 拓扑新增可点击的「代理 Wi-Fi」节点，可查看状态、启停接管、管理共用分流规则、复制网关和打开接入指南。名称与密码通过系统共享设置查看或修改，不展示不可靠的旧配置。

## 重点查看实际代理用量

- 「设备接入」突出当前代理入口的上传、下载和合计，例如 `127.0.0.1:7897`，并单独显示本机直连量。
- 点击设备 IP 或「查看设备与域名明细」，按设备、日期、代理入口、服务和域名查看代理／直连记录。
- 每条连接记录实际使用的上游端口；更换代理配置不改写历史归属，失败后回退直连的字节计入直连。
- 按日持久化设备、域名/IP、出口及流量汇总，重启保留。旧版总量没有出口信息，仍保留但标为未分类；新明细从升级后开始记录。
- 统计口径是本网关实际转发字节，不包含 Mac 其他应用使用代理端口的流量、网络协议开销或绕过本网关的流量；不等同于服务商账单。记录域名/IP，不记录完整 URL 或 HTTPS 页面内容。

## 修复与稳定性

- 修复开启热点时只保存配置、后台仍运行旧核心的问题；更新并重启已有 launchd 服务时保留原配置路径和环境。
- 修复 fake-IP UDP 重定向绕过 QUIC 阻止规则的问题，使客户端能够回退 TCP。YouTube 与 Google Play 已在本机热点上实测恢复。
- 隔离热点防火墙规则，清理本项目遗留入口，避免关闭系统共享所需的全局转发与防火墙。
- 兼容不同 SwiftPM 输出目录，支持通过 SDKROOT 选择本地 macOS SDK。

## 升级说明与使用边界

1. 安装新版 App 后重启核心；系统可能要求管理员授权。只替换 App 而不重启旧核心，无法启用新增统计。
2. 热点需要 Mac 有线联网并保持唤醒。Wi-Fi 名称和密码由 macOS 管理；修改时可能需要暂时关闭互联网共享。
3. 热点复用 App 的设备策略和域名分流规则；上游代理软件仍执行自身规则。
4. HTTP 上游主要承载 TCP；游戏 UDP 仍按原设计直连，互联网共享增加一层 NAT。游戏联机效果需要在主机上实测。
5. 设备按 IP 归属，DHCP 重新分配地址时需留意归属变化。历史汇总每约 5 秒落盘，异常断电可能丢失最后一小段数据。
