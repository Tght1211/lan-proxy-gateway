# Apple TV 接入

[返回图文手册](user-guide.md)

Apple TV 不安装本项目。先在网关电脑配置可用代理，再让电视连接网络。

## 推荐：Mac 热点

在有线 Mac 完成 [热点创建与接管](user-guide.md#wifi)，然后在 Apple TV 的 **设置 → 网络 → Wi-Fi** 选择 Mac 热点、输入密码。IP 与 DNS 自动获取。

打开实际需要的视频服务并播放，再在网关“流量记录”查看新连接与出口。服务能否播放、可见地区和内容由账号、服务及实际出口决定，本项目不保证流媒体解锁。

## 进阶：原网络中的静态网关

先按 [静态网关说明](user-guide.md#static) 设置主机并检查 DNS。Apple TV 的“设置 → 网络”中打开当前 Wi-Fi 或以太网配置：

1. “配置 IP”选手动，填写未占用的设备 IP 和真实子网掩码；路由器填网关电脑的局域网 IP。
2. 使用网关 DNS 时，“配置 DNS”选手动，填写网关电脑 IP。
3. 保存后重新访问服务，回 App 查看连接。

菜单随 tvOS 版本变化，以实际选项为准。不要把 `127.0.0.1` 当远端电脑地址。

## 停用和故障

热点路线切回原 Wi-Fi；静态网关恢复自动 IP/DNS 或原网络设置。部分服务异常时先查具体域名的实际出口，再核对上游代理及账号/地区要求，见 [常见问题](faq.md)。
