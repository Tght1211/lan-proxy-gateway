# LAN Proxy Gateway 原生改造

以用户确认的 lan-proxy-gateway-demo.html 为交互基准，产品名称唯一，取消双界面模式。保留现有 Go 核心、CLI 和 SwiftUI 技术栈，不把演示 HTML 或示例数据嵌入产品。

## 页面与边界

- 网络总览：真实设备 → 接入方式 → 热点网关／LAN 入口 → 设备策略 → 域名规则 → 出口。节点均以 sheet 编辑；只在总览出现。连接采样后播放，颜色按域名稳定映射，图标线条短动画，无矩形发光。首字节数据不足不伪造响应毫秒数。
- 网络出口：紧凑双列卡片；已配置代理、直连、拒绝。代理编辑／探测，直接展示稳定性时间条；直连看累计流量；拒绝看规则与真实记录。多代理池按用户后续范围答复决定，当前不以演示 A/B/C 冒充真实功能。
- 配置规则：代理规则、自学习、网络出口三个 tab，默认规则。复用列表／文本编辑和分组排序；显式规则优先于自学习。自学习配置与学习记录独立页面内呈现。
- 设备接入：Wi-Fi、静态 IP、PAC、HTTP 四个 tab；Wi-Fi 优先，三步简短指南，通用设备／游戏主机，频段、硬件地区建议；网络名默认 GrandLine，密码备忘使用 Keychain，不修改系统 Wi-Fi。
- 流量记录：复用真实连接表与筛选，保留应用归类、设备、出口、结果和流量；不重复总览吞吐图。
- 设置：功能与接入、通用、版本、CLI 与 Agent、运行日志；控制操作走现有接口，可用性由运行态确认；不提供保存后无效的假开关。配置与日志地址来自核心。

## 结构

导航与外壳独立；NetworkPresentation 为 Foundation-only 的纯投影层；NetworkTopology 只绘图与发出用户意图；NetworkSheets 集中对应节点 sheet；各页面组合现有业务组件。AppModel 继续负责命令与状态刷新，GatewayClient 负责 CLI/API。协议模型保持向后解码兼容。

## 验收

Swift 构建、模型回归、Go 全量测试；真实数据缺失显示空态，不展示样本；连接动画去重、重启重置、有界缓存；未知入口不猜测；停止／失败不能显示正常。保留用户未提交更改，不自动提交混合改动，不自动重启正在共享的网关。

## 当前交付与待扩展

已接入六模块原生界面、图标拓扑模态路由、首响应耗时、有界延迟回放、自学习参数保存和运行时应用、规则编辑冲突保护、Wi-Fi备忘与五类设置。Go核心仍使用一个上游代理；代理池/多源/显式兜底链、热点与静态网关同时透明接管、App原位升级属于待扩展能力。当前不会在产品中展示虚构的代理B/C。

学习等待参数：direct_wait_seconds、proxy_wait_seconds、max_direct_wait_seconds、cooldown_seconds、memory_minutes，分别默认5/5/30/30秒及10分钟。CLI通过 gateway learning configure '<JSON>' 保存，与UI共享状态文件。旧核心没有这些字段时UI禁用参数调整，仍可配置确认次数及记录方式。

首响应耗时 response_ms 表示第一段转发载荷至第一段上游数据的间隔，不含初始拨号；不把它标为ping或业务成功。HTTPS业务内容不解密。

构建验证使用 SDKROOT=/Library/Developer/CommandLineTools/SDKs/MacOSX15.2.sdk。原生预览位于 dist/LAN Proxy Gateway Native Preview.app；现有后台网关不自动重启。

## 设计稿还原补充（2026-09-30）

统一原生视觉组件集中在 StudioDesign.swift：Bare outline icons、Tab、按钮、下拉框与表单字段。Graphite/Light 采用演示稿的最终色板、14pt 卡片圆角、22pt 内边距。侧边栏为手工按钮导航，选中态为青绿色浅底；核心操作收进工具菜单，顶部保留出口状态。总览为四项指标、横向图标拓扑、等高稳定性与一分钟吞吐卡片；出口为双列卡片；规则/设备/设置使用统一 Tab。

设备可见性按实际正字节传输时间 last_traffic_at 计算，不使用连接打开/关闭时间。超过10分钟为灰色、超过24小时不显示；新流量恢复显示。保留设备名称、规则和历史流量，仅隐藏当前拓扑/接入列表条目。旧核心未返回该字段时通过累计字节变化维护观察时间，避免轮询刷新活跃时间。

设备识别采用最近30分钟内的数据响应和多个平台信号。Google Play/Heytap/移动推送归为手机，系统更新/Steam客户端归为电脑；微信等跨平台服务阻止误判主机，单一游戏商店访问不识别为PlayStation。平台证据冲突显示未知，用户手动命名始终优先。
