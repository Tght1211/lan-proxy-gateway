# PlayStation 5 接入

[返回图文手册](user-guide.md) · [游戏联机排查](faq.md#gaming)

PS5 不安装网关软件。有线 Mac 可以创建热点，让主机自动获取地址。

## 推荐：Mac 热点

1. 在 Mac 完成 [热点路线](user-guide.md#wifi)，确认 App 显示“热点接管已开启”。
2. PS5 进入 **设置 → 网络 → 设定 → 设定互联网连接**，选择 Mac 创建的热点并输入密码。
3. IP 地址、DNS 选自动，DHCP 主机名不指定，代理服务器不使用。
4. 运行互联网连接测试，再实际打开商店/下载或进入游戏；回 App 查看对应新连接。

看不到热点时，检查系统共享和实际可用信道；主机版本与无线环境可能影响兼容性，见 [热点详细说明](hotspot-setup.md)。

## 进阶：静态网关

先完成 [主机静态接入配置](user-guide.md#static)。在已选网络的高级设定中：IP 改为手动，填同子网的空闲设备 IP 和真实掩码；默认网关填电脑局域网 IP；使用网关 DNS 时，将主/次 DNS 指向电脑（不允许重复时次 DNS 留空）。代理服务器不使用。

不要同时照抄热点的自动参数和静态网关参数；切换接入模式会影响现有热点设备。

## 关于联机

商店能打开不代表 UDP 对战/语音一定正常。网关没有通用 UDP 代理，不保证 NAT 类型或延迟改善。先与直接连接原路由器比较，按 [游戏排查](faq.md#gaming) 定位。

停用时，热点设备改连原 Wi-Fi；静态网关设备恢复自动 IP/DNS 或原设置。见 [停止与恢复](user-guide.md#stop)。
